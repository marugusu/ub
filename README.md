# Eesti uBlock Origin Filter (uB)

Eesti veebisaitide reklaamiblokeerija reeglite nimekiri uBlock Originile.

- **Repositoorium:** https://github.com/marugusu/ub
- **Filtri toorlink (Raw URL):** `https://raw.githubusercontent.com/marugusu/ub/main/list.txt`

---

## Kuidas tellida uBlock Originis (Automaatne uuendamine)

1. Ava brauseris **uBlock Origin juhtpaneel** (Dashboard / hammasratta ikoon).
2. Mine vahekaardile **Filter lists** (Filtrite nimekirjad).
3. Keri lehe lõppu sektsioonini **Custom** (Kohandatud).
4. Märgi linnuke **Import...** (Impordi...).
5. Kleebi avanevasse tekstikasti link:
   ```text
   https://raw.githubusercontent.com/marugusu/ub/main/list.txt
   ```
6. Vajuta lehe ülaosas **Apply changes** (Rakenda muudatused).

---

## Alternatiiv: Lokaalne kasutamine (Minu filtrid)

1. Ava [list.txt](list.txt) ja kopeeri selle sisu.
2. Ava uBlock Origini juhtpaneel -> **My filters** (Minu filtrid).
3. Kleebi sisu tekstikasti ja vajuta **Apply changes**.
